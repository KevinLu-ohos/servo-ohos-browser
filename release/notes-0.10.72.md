# Servo Browser for HarmonyOS PC — 0.10.72

侧载包：`servoshell-ohos-2in1-0.10.72-unsigned.hap`（未签名，需自行签名或用侧载工具安装）
内核：Servo 0.7.0（含本仓库 `patches/0001-servo-ohos-browser.patch` 的 OpenHarmony 端口改动）

## 本版重点

- **下载改为流式落盘**：不再等整个响应读完再交给页面侧，而是复用同一个网络响应，边收边写盘，
  大文件不再受内存缓冲限制，进度与速率按真实写入量更新。
- **只接管 2xx 响应**：只有成功响应才走下载管线，`4xx` / `5xx` 仍交给文档管线渲染错误页，
  修掉了此前的**「0 字节假完成」**——即重定向、`204`、空响应被当成下载成功、留下一个打不开的空文件。
- **文件名补齐扩展名**：`Content-Disposition` 常常只给光秃秃的名字，URL 末段也可能是 `/download?id=123`；
  现在缺扩展名时按响应 MIME 反推一个补上（推不出来就保持原名，不编造假扩展名）。
- **下载完成后自动保存到「下载/Servo」**：内核先写到应用沙箱，ArkTS 侧下完再搬进公共下载目录，
  列表里会标注「下载/Servo」；该行为默认开启，可在设置里关闭。
- **下载面板动作齐备**：暂停 / 继续 / 取消 / 重试 / 打开与删除均可从面板直接操作，记录持久化，
  重启后未完成的记录标记为「已中断」并可重试。
- **版本号**：0.10.72（`versionCode` 10000072）。

## 已知问题（务必先读）

### 本版特别提醒

1. **返回 / 前进：正在重构，本版暂不可用。** 工具栏的返回、前进按钮在本版**不会生效**。
   相关实现正在重写，计划下个版本恢复；本版请暂用地址栏重新输入，或从书签 / 历史面板跳转。
2. **按钮 hover 反馈失效。** 鼠标悬停在工具栏与面板按钮上不再有高亮 / 变色反馈。点击本身仍然有效，
   只是缺少指针反馈，正在修复。
3. **图标居中 / 对齐仍有偏差。** 工具栏与设置页的部分图标存在可见的视觉偏移，
   **内屏与外接屏均存在**，与缩放 / 安全区计算有关，正在排期处理。

### 长期存在

4. **中文输入**：部分站点首次点击输入框后需要再点击一次；个别站点偶发不可用。英文输入正常。
5. **下载**：功能仍在完善，**不保证下载一定成功完成**（权限、网络、需要登录态的链接、blob 4MB 上限等）。
6. 无 DRM（付费流媒体不可用）、单进程无站点隔离。
