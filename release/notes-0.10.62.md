# Servo Browser for HarmonyOS PC — 0.10.62

侧载包：`servoshell-ohos-2in1-0.10.62-unsigned.hap`（未签名，需自行签名或用侧载工具安装）
内核：Servo 0.7.0（含本仓库 `patches/0001-servo-ohos-browser.patch` 的 OpenHarmony 端口改动）

## 本版重点

- **书签**：地址栏星标一键收藏/取消，书签栏可开关，面板内可按标题或网址搜索、单条删除。
- **历史**：访问记录持久化到应用私有 RDB（`servo_library.db`，书签与历史同一库两张表），
  面板按天分组、支持搜索、单条删除，清空需二次确认；新标签页新增「最近访问」磁贴。
  写入策略为内存缓存优先 + 串行异步落库，同 url 60 秒内合并，库内上限 5000 行、读取窗口 300 行。
- **界面整改**：书签星标与地址栏基线对齐；搜索行只保留 placeholder 与搜索按钮；
  清空按钮独立成行并带弹簧 / 交叉淡入过渡；书签与历史列表改为分组卡片 + 分隔线。
- **版本号**：0.10.62（`versionCode` 10000062）。

## 已知问题（发布说明中明确保留）

1. **中文输入**：部分站点首次点击输入框后需要再点击一次；个别站点偶发不可用。英文输入正常。
2. **下载**：功能仍在完善，**不保证下载一定成功完成**（权限、网络、需要登录态的链接、blob 4MB 上限等）。
3. 无 DRM（付费流媒体不可用）、单进程无站点隔离。

## 校验

```bash
shasum -a 256 servoshell-ohos-2in1-0.10.62-unsigned.hap
```
